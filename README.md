Project Toko Novel Sederhana
Fitur program:
1.Menampilkan daftar novel.
2.Menambah novel.
3.Membeli novel.
4.Menghitung total harga.
5.Melihat stok novel.
6.Keluar dari program.

Penjelasan OOP pada Project Toko Novel:
1.Class: Cetakan untuk membuat objek. Dalam project ini terdapat class Novel dan TokoNovel.
2.Object: Hasil dari class. Contohnya novel Laskar Pelangi, Dilan 1990, dan Bumi.
3.Constructor: Digunakan untuk memasukkan data awal novel, seperti judul, penulis, harga, dan stok.
4.Attribute: Data yang ada di dalam class, seperti judul, penulis, harga, dan stok novel.
5.Method: Fungsi untuk menjalankan perintah, seperti menampilkan novel, menambah novel, dan membeli novel.
6.Encapsulation: Menggabungkan data dan fungsi dalam satu class agar lebih teratur.
